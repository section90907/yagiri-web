# デザイン方針

## 矢切ブルワリー(醸造所)側 — トップ / STORY / BEER 101 / JOURNAL / FUTURE / 404
- コンセプト: 和モダン(矢切の「矢」)× トレイジャン系欧文のカッコよさ。2026-10 に「C×A」案で決定。
- 色: 黒が主役、暗い赤(えんじ)がアクセント。
  - 背景 `#0B0B0B` / 面 `#141414` `#161616` / 文字 `#EFE9DC`(補助 `#CFC8B8` `#DCD4C0`)
  - えんじ `#7A1E2B`(ボタン・購入ブロック・線) / 金 `#C9AA6E`(細線・番号・英字ラベル) / 深緑 `#142A24`(セクション背景を1ブロック程度)
- 書体: 欧文見出し Cinzel(Trajan代替) / 和文見出し・本文 Shippori Mincho / UI・本文 Zen Kaku Gothic New
- 見出しの型: ローマ数字(I. II. …)+ Cinzel 英字 + 小さな明朝の和文(例: II. / Our Product / 泡製品)
- モチーフ: 金の一本線+矢じり。縦書きの「矢切で、醸す。」をヒーローで大きく出す。
- 製品欄の表記は「Our Product / 泡製品」(既存サイトからの継承)。
- アメリカンダイナー/アンティーク調の要素を醸造所側に一切入れない。ロゴと誤解されるアイコンも入れない。

## YAGIRIYA 側 — /yagiriya/
- コンセプト: 1960年代アメリカンアンティークのパブリックハウス。ロゴ(`public/images/yagiriya_logo.png`、YAGIRI BREWERY × CANDY STORE ROCK)に合わせる。
- 色: ロゴの深緑 `#145E50` が主役、生成り `#F4ECD9` 地、ベージュ `#E3D3A8`、二重線の罫。
- 書体: 見出し Alfa Slab One / 和文 Zen Maru Gothic
- 醸造所側の黒×金×Cinzel は使わない。

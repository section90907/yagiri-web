# AGU(アグ)— 矢切ブルワリーの量の単位

一杯の純アルコール量が、厚生労働省の目安(1日平均 約20g)の何倍か。**1 AGU = 約20g**。2026-10-25 に制定。正式名は、基準の年を付けた「AGU2026」。

## 決まり
- 計算: 量(ml)× 度数(%)÷ 100 × 0.8 ÷ 基準(g)。**小数第1位**。
- 基準の数字・年・制定日は **`site.config.json` の `agu`**(`baseG` `baseYear` `since`)の1か所だけ。ON TAP、ビール診断、BEER 101(`#agu`)の数字と文言は、ここから出る。
- 容量: クラフトビールは レギュラー 260ml / ビッグ 470ml。バドワイザーだけ 300ml / 500ml(`content/taplist.json` の `ml`)。
- 飲み比べセット(100ml×3)には、AGU を載せない(枠が狭いため。オーナー判断)。
- 表示する場所: ON TAP のカード(レギュラー・ビッグ)、ビール診断の結果、BEER 101(用語集と、`#agu` の説明・注意書き・変更の記録)、読みもの `/journal/agu/`。

## 厚労省の目安が変わったとき
1. `site.config.json` の `agu` を直す(`baseG` と `baseYear`。たとえば 2030年に 10g なら `baseG: 10`, `baseYear: 2030`)。
2. 直した日を `since` に入れず、**BEER 101 の「変更の記録」の表に、1行足す**(`src/pages/guide/index.html`)。制定日(`since`)は、最初の制定日のままにするか、運用を決めてから変える。
3. 読みもの `/journal/agu/` の「記録」に、1行足す。
4. 数字が変わるので、ON TAP と診断の表示が、自動で変わることを確認する。昔の投稿・印刷物の数字とは、食い違うので、「AGU20XX」と年を添える。

## 注意書き(必ず出す)
- 安全な量を示すものではない。
- 1 AGU は、お酒に強い人の1日平均の目安。女性・高齢の方・お酒に弱い体質の方は、これより少ない量が適当とされる。
- ご自身の許容量を、AGU でも把握し、無理のない量を、ご自身で判断してもらう。
- 20歳未満、妊娠中・授乳中の方は飲まない。飲酒運転は禁止。
- 「健康になる」「減らせる」などの、効能を思わせる言い方はしない。「日本初」などの断言もしない(裏づけが取れないため)。

## 日付の証拠(「2026年から取り組んでいた」と言えるように)
- 読みものの日付は、あとから書き換えられるので、それだけでは弱い。
- GitHub の公開リポジトリの、コミット・マージの日時(履歴は書き換えない)、公開日の Wayback Machine(Save Page Now)への保存、インスタの投稿日時、Search Console のインデックス日を、残す。
- さらに強くするなら、公証役場の確定日付、電子公証。
- 商標: 「AGU」の登録の有無を、J-PlatPat などで確認する(未確認)。

# 読みもの(JOURNAL)のタイトル動画

記事の冒頭に出る、黒地に言葉が出ては消える動画(10秒ループ・音なし・矢切カラー)。

## 見た目の決まり
- 黒地(#0B0B0B)。言葉はクリームと金、行の頭と、最後のタイトルの下の線は、えんじ
- 書体は、サイトと同じ「しっぽり明朝」(日本語)と Cinzel(英字)
- 言葉は、**縦書き・横書きをランダム**に選んで現れ、**中央へ向かって、少し小さくなりながら消える**。**重要な言葉ほど大きい**(大・中・小の3段階)
- 途中で、短い言葉が横に流れて止まり、最後に、カテゴリとタイトルが中央に出る
- 画面は 16:9(1280×720)。記事の冒頭は、動画。**動きを減らす設定の端末では、ポスター(静止画)のまま止まる**。一覧とトップは、ポスター(静止画)だけを使う
- 動画の言葉は、**記事の本文・見出し・要点から選ぶ。事実と違うこと・出典のないことは書かない**

## 作り方(新しい記事を足したとき)
1. `content/title-videos.json` に、記事の slug で1件足す。`category`(front matter と同じ)、`title`(短く)、`sweep`(横に流す短い言葉)、`seed`(縦横と配置が変わる)、`items`(「大|中|小:言葉」を8個ほど。大3・中3・小2が目安)
2. `python3 scripts/title-video/make.py <slug>` を実行する(Python3・Pillow(raqm 付き)・numpy・ffmpeg が要る。**サイトのビルドには使わない、開発用の道具**。書体は初回に Google Fonts から `~/.cache/yagiri-title-video/` へ取ってくる)
3. `public/images/journal/<slug>.mp4` と `<slug>.jpg` ができる。記事の front matter に `image: /images/journal/<slug>.jpg` と `video: /images/journal/<slug>.mp4` を書く
4. 縦に収まらない言葉は、自動で横書きになる。重なりが気になるときは、`seed` を変えて作り直す
- 動画が無い記事は、画像(`image`)、それも無ければ、何も出さない
- `image` は、一覧・トップの最新記事・SNS で共有されたとき(og:image)にも使う
